DEFECT #12: Sessions Not Stored in Redis
-----------------------------------------
Severity: MEDIUM
Category: Architecture Mismatch

README Documentation States:
  "Sessions are stored server-side in Redis"

Actual Implementation:
  Sessions use Flask's default client-side cookie-based session storage
  No Redis configuration or imports exist in the codebase

Reproduction Steps:
  1. Review all project files
  2. Search for "redis" or "session" imports
  3. Observe: No flask-session or redis-py packages
  4. Observe: No Redis configuration in app.py

Code Evidence:
  - No redis imports in any file
  - No Flask-Session configuration
  - requirements.txt does not include redis or flask-session

Fix Required:
  Either implement Redis session storage (install flask-session and redis):
  ```python
  from flask_session import Session
  app.config['SESSION_TYPE'] = 'redis'
  app.config['SESSION_REDIS'] = redis.from_url('redis://localhost:6379')
  Session(app)
  ```
  Or update README to state "Sessions are stored in browser cookies"
