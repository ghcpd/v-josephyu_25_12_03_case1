README DEFECTS AND MISMATCHES
=============================

DEFECT #1: Incorrect Quick Start Command
---------
Location: README.md - Quick Start section
Issue: The command uses non-existent flags
  Documented: python app.py --host=0.0.0.0 --port=8080
  Actual Code: app.run(debug=True) in app.py does not accept these flags
  Error: TypeError: run() got unexpected keyword arguments '--host' and '--port'
Reproduction:
  $ python app.py --host=0.0.0.0 --port=8080
  TypeError: run() got unexpected keyword arguments
Expected Behavior: Should use environment variables or Flask's default configuration
Fix: Use `flask run` or modify app.run(host='0.0.0.0', port=8080)
